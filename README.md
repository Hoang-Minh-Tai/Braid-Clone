<h1>🧩 Braid Clone</h1>

A personal clone project inspired by <strong>Braid</strong> (Jonathan Blow) — a 2D puzzle-platformer focused on implementing a <strong>time-rewind mechanic</strong> and exploring how time manipulation affects gameplay, physics, and audio.

This project was created <strong>solely for learning and portfolio purposes</strong>.

<h2>✨ Features</h2>

<h3>⏪ Time Rewind Mechanic</h3>
<ul>
  <li>Rewind player movement and interactions</li>
  <li>Restore object states accurately over time</li>
  <li>Custom state recording system for gameplay objects</li>
</ul>

<h3>🎵 Rewindable Audio</h3>
<ul>
  <li>Music and sound effects synchronize with time reversal</li>
  <li>Audio playback rewinds smoothly with gameplay</li>
</ul>

<h3>🧱 Shader Programming & Visual Effects</h3>
<ul>
  <li>Custom shaders for environmental effects</li>
  <li>Post-processing effects to visualize time manipulation</li>
  <li>Visual feedback to enhance rewind clarity</li>
</ul>
